UI 一比一对齐

先把「哪里已经一致、哪里还没」量出来，再动手改。颜色 token 是逐值比对的，不是目测。

颜色 token 100% 一致 尺度过关 5 项 待改 8 项

一致的（已一比一）

✓ 颜色 token 177 个变量，Light/Dark 双模式，色值 100% 相同
✓ 字号尺度 --text-10 到 --text-28，与上游完全一致
✓ 间距/圆角 --space-0 到 --space-96、--radius-* 同源
✓ 内容区宽度 880px 居中
✓ 字体栈 Inter + 中文回退链一致

不一致的（这轮要改）

! 用户气泡宽度 上游 min(720px, 100%-96px)；我的是 min(488px, 82%) —— 明显偏窄
! 用户气泡内距 上游 14/10px；我的是 16/12px —— 偏胖
! 消息悬停操作条 上游每条消息有复制/分支/编辑/更多 + 时间（24×24 按钮、14px 图标）；我没有
! ↓ N 条新消息药丸 上游有；我没有，上翻时新内容完全无感
! 滚动锚定 上游独立视口层，上翻不拽人；我流式输出会强行拽回底部
! 发送键语义 上游 Enter 恒为发送，Ctrl+Enter 才是插话；我跑着时 Enter 变插话
! 侧栏菜单 上游 hover 90ms 打开、160ms 关闭；我要点击且移开即消失
! 零星字号 我写过 9px / 11.5px，不在规范尺度上（已清）
结论：底子已经是一比一的（177 个颜色变量逐值相同）， 不像的地方全部出在用法层 —— 气泡尺寸、悬停操作条、滚动锚定、发送键语义这些。 这轮就改这 8 项。
